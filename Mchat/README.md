# Chatty – Real-Time Full-Stack Chat Application

Chatty is a modern full-stack real-time messaging application built with:

- **React + Zustand + Tailwind CSS** (frontend)
- **Node.js + Express + MongoDB** (backend)
- **Socket.io** for real-time communication
- **JWT authentication with HttpOnly cookies**
- **Jest** for automated testing

This project implements a real-world WhatsApp-style chat experience with:
authentication, live messaging, status updates, and contact lists.

---

## 🚀 Features

### ✅ User Features
- User registration & login  
- Protected routes using JWT + cookies  
- Update profile (avatar, name, email)  
- Real-time chat (Socket.io)  
- Online/offline user detection  
- View all contacts  
- Light/dark UI  
- Mobile-friendly responsive layout  

### 🔥 Admin / Dev Features
- Seeder script to populate sample users  
- Organized backend folder structure  
- Jest test environment preconfigured  
- Modular controllers, middleware, and routes  
- Environment-based configuration  

---

## 🧱 Tech Stack

### **Frontend**
- React (Vite)

- Tailwind CSS

### **Backend**
- Node.js
- Express.js
- MongoDB + Mongoose

### **Testing**
- Jest
