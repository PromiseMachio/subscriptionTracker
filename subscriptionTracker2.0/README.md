# 🛠️ Backend

**Path:** `/backend`

### Tech Stack

* Node.js
* Express.js
* MongoDB (Mongoose)
* JSON Web Tokens (JWT)
* ACJET
* Nodemon
* Dotenv

### Features

* User authentication 
* Middleware (For authentication)
* Subscription creation & cancellation
* CRUD
* Endpoints

### Install Dependencies

```
cd subscriptionTracker
npx express-gebnerator --no-view --git ./
```

### Environment Variables

Create a `.env` file:

```
PORT=5000
MONGODB_URI=your-mongodb-connection
JWT_SECRET=your-secret
JWT_EXPIRES_IN=xxx 
ARCJET_KEY=xxx
ARCJET_ENVY=xxx
NODE_ENV=xxx
```

### Run the Backend

```
npm run dev
```
